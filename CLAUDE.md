# workflowy-userscripts

A solo collection of standalone browser userscripts for WorkFlowy.

- `import-export/` — import/export userscript (`import-export-V0.js`)
- `presentation-mode/` — top-level-only slides for Presentation Mode (`workflowy-presentation-top-level-slides.user.js`)

## Agent skills

### Issue tracker

Issues and specs live as local markdown files under `.scratch/<feature-slug>/`. See `docs/agents/issue-tracker.md`.

### Domain docs

Multi-context: `CONTEXT-MAP.md` at the repo root points to one `CONTEXT.md` per script, with decision records in each script's own `docs/adr/`. Created lazily as terms and decisions get resolved. See `docs/agents/domain.md`.
